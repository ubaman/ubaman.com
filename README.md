# ubaman.com

Sitio oficial de Ubaman Coaching.

UBAMAN COACHING — SITIO WEB

ARCHIVOS
- index.html: textos, enlaces, precios y estructura.
- styles.css: colores, diseño y adaptación a celular.
- script.js: menú, animaciones y selección de planes.

ANTES DE PUBLICAR
1. En index.html y script.js, cambia 5210000000000 por tu WhatsApp con código de país.
2. Cambia los precios y lo que incluye cada plan en index.html.
3. Reemplaza los enlaces # de Twitch, YouTube y TikTok.
4. Puedes cambiar el texto de presentación en la sección "Tu coach".

SUBIR A GODADDY
1. Entra a tu cuenta de GoDaddy y abre cPanel / Administrador de archivos.
2. Abre public_html.
3. Sube index.html, styles.css y script.js directamente dentro de public_html.
4. Abre tu dominio y confirma que cargue correctamente.

No subas este README si no quieres que quede disponible públicamente.
